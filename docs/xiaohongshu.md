# 只看｜B 站极简首页

隐藏 B 站首页推荐流，只保留搜索框和你固定的 UP 主。

支持全站搜索、UP 主内搜索、点击直达投稿页，以及一键开启或关闭极简首页。

免费下载，选择一种安装方式：

- **脚本版**：[Greasy Fork 下载](https://greasyfork.org/zh-CN/scripts/600653-%E5%8F%AA%E7%9C%8B)。先安装 Tampermonkey，再点击「安装此脚本」。也可以在 Greasy Fork 搜「只看」，作者为 qwertybuaa。
- **Chrome 扩展版**：[GitHub Releases 下载](https://github.com/qwertybuaa/zhikan/releases/latest)。下载 `zhikan-chrome` 开头的 ZIP 并解压，在 `chrome://extensions` 开启「开发者模式」，点击「加载已解压的扩展程序」，选择解压后的 `bili-focus` 文件夹。
