## 只看想看的。

打开 B 站，首页只留下一个搜索框，和你亲手固定的 UP 主。

- **直达想看的人**：固定常看的 UP 主，点击进入投稿页。
- **搜到想学的内容**：支持全站搜索，也能只搜某位 UP 主。
- **自己的首页，自己选**：从空白列表开始，随时添加、编辑和移除。
- **一键切换**：在 Tampermonkey 菜单中开启或关闭极简首页。

### 安装

安装 Tampermonkey，点击本页「安装此脚本」，然后打开 B 站首页。

新版 Chrome 请在 Tampermonkey 的扩展详情中开启「允许运行用户脚本」。

### 添加 UP 主

点击首页的「添加 UP 主」，填写空间链接或 UID；也可以在 UP 主空间页，从 Tampermonkey 菜单选择「固定当前 UP 主」。

固定列表和开关由脚本管理器保存。
