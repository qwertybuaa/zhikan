# Asset sources

`bilibili.svg` contains the wordmark path from the Bilibili search page SVG
(`https://search.bilibili.com/`, `svg.search-logo`), retrieved 2026-10-17.
The source geometry is preserved. Page-specific attributes are removed and
the fill is set to Bilibili's `--brand_pink` color, `#FF6699`.
The Bilibili name and logo belong to their respective owner.

`mark.svg` is the original 只看 eye/play logo: a white eye with a pink play
symbol on a Bilibili-pink rounded square. The PNG variants and `assets/logo.svg`
are rendered from this vector. All assets are bundled locally.
